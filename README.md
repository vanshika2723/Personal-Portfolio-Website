# Personal Portfolio Website

A full-stack personal portfolio website built to showcase my skills, projects, education, and contact information.

## 🚀 Live Demo

https://personal-portfolio-website-three-phi.vercel.app/

## 📌 Features

- Responsive portfolio design
- Hero section
- About section
- Skills section
- Dynamic projects from MongoDB
- REST API using Node.js and Express.js
- Contact form
- Contact messages stored in MongoDB
- Responsive design for mobile, tablet, and desktop
- GitHub and live project links
- Full-stack frontend and backend integration

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- MongoDB Atlas

### Tools & Deployment
- Git
- GitHub
- VS Code
- Vercel
- Render
